# Nexa Next Admin

React + Next.js implementation of the Nexa Admin starter. It keeps the same product structure, demo auth flow, navigation, i18n keys, theme modes, request layer, table demos, component docs, and page templates as the Vue version while using React, Next App Router, Context state, shadcn/ui, and Tailwind CSS.

## Scripts

```bash
pnpm install
pnpm dev
pnpm check
```

`pnpm dev` runs on port `5174`, matching the original template convention.
